Every country we can move money in, with the number format to expect there.

A country appears here only when at least one of its providers is actually usable — so
this list can't advertise somewhere nothing works.

```bash
curl https://connect.tchokopay.com/v1/countries \
  -H "Authorization: Bearer tchoko_live_..."
```

```json
[
  {
    "country": "CM",
    "name": "Cameroon",
    "currency": "XAF",
    "dialCode": "+237",
    "phoneDigits": 9,
    "phoneExample": "670000000"
  }
]
```

| Field | Description |
|---|---|
| `country` | ISO code. Send this as `country` when you collect or disburse. |
| `currency` | What that country transacts in. |
| `dialCode` | International dialling prefix. |
| `phoneDigits` | How many digits a local number has. Validate against this before calling us. |
| `phoneExample` | A correctly shaped number, for your own tests and placeholder text. |

<Callout type="info">
  `phoneDigits` and `phoneExample` are absent for some countries. Where they are missing,
  skip the length check and let us validate the number — do not assume a length.
</Callout>

## Caching this

Safe to fetch once at start-up and keep for an hour. It changes only when we open a new
market.
