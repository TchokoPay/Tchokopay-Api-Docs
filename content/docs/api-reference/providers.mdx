Every network the platform supports, across every country.

```bash
curl https://connect.tchokopay.com/v1/providers \
  -H "Authorization: Bearer tchoko_live_..."
```

```json
[
  { "provider": "mtn_cm",    "name": "MTN MoMo",     "method": "MOBILE_MONEY", "country": "CM" },
  { "provider": "orange_cm", "name": "Orange Money", "method": "MOBILE_MONEY", "country": "CM" }
]
```

| Field | Description |
|---|---|
| `provider` | The code to send as `provider` when you collect or disburse. |
| `name` | What the network calls itself. Show this to your customer, not the code. |
| `method` | The class — `MOBILE_MONEY` for every network on it. It cannot tell two networks apart; `provider` is the field that can. |
| `country` | `null` for a borderless provider. |

<Callout type="warn">
  This is the catalogue — what the **platform** supports. What **your account** may use
  can be narrower. Build your picker from
  [`GET /v1/account/providers`](/docs/api-reference/account-providers) instead, or your
  customers will be offered networks that refuse them.
</Callout>
